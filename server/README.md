# Horas Sistemas API

Backend en TypeScript con Express y Sequelize para registrar personas, cargos y novedades de entrada y salida.

## Requisitos

- Node.js 20 o superior
- MySQL 8 o MariaDB compatible

## Configuracion

1. Copia `.env.example` a `.env`.
2. Crea la base de datos con el script en `database/schema.sql`.
3. Instala dependencias con `npm install`.
4. Ejecuta `npm run dev`.

## Scripts

- `npm run dev`
- `npm run build`
- `npm run start`
- `npm run db:migrate`
